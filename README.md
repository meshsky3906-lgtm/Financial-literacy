## 🌟 核心特色與財商理念

### 1. 50 / 30 / 20 黃金資產配置模型 (Elizabeth Warren 經典法則)
- **50% 必要需求 (Needs)**：維持生存與工作的固定支出（房租、三餐、水電瓦斯、交通通勤、基本醫療與保險）。
- **30% 彈性慾望 (Wants)**：提升生活品質與適度犒賞（外食大餐、服飾精品、娛樂展覽、旅遊休閒）。
- **20% 投資與安全儲備 (Invest & Savings)**：讓未來的自己更有錢（指數化 ETF 投資、緊急預備金累積、自我成長進修）。

### 2. 信用卡「零錯亂」財商理解方式
- **【刷卡當下即支出】**：刷卡的瞬間立即記錄消費項目與財商標籤，及時扣減當月預算，杜絕「假性富裕」心理。
- **【繳卡費是內部轉帳，非重複支出】**：繳納信用卡帳單時，屬於「銀行活存 ➔ 信用卡帳戶」的沖銷轉帳，系統絕不重複扣減支出。
- **【真實可用現金 (Real Available Balance)】**：自動計算 `活存存款 - (玉山待繳 + 富邦待繳)`，讓您一眼看清真正能自由支配的資金。

### 3. 雙信用卡 30% 信用額度使用率嚴格風控 (玉山 & 富邦)
- 銀行與聯徵中心評估個人信用時，會高度關注**「信用卡額度使用率（當月刷卡 ÷ 總額度）」**。維持在 30% 以下能打造最頂級的個人信用評分！
- **預設配置**：
  - 💳 **玉山銀行信用卡**：總額度 $60,000 ➔ **每月安全刷卡上限：$18,000 (30%)**
  - 💳 **富邦銀行信用卡**：總額度 $60,000 ➔ **每月安全刷卡上限：$18,000 (30%)**
- 系統內建即時進度刻度與超標預警，刷卡超過 $18,000 時立即發出風控提示。

### 4. 🛡️ 緊急預備金防護盾
- 動態計算當前預備金可支撐幾個月的生活固定開銷（以 3~6 個月為黃金安全基準線）。

### 5. ⚡ 隨時極速記帳體驗
- 手機/電腦自適應，一鍵隨時開啟記帳。
- 支援「雙軌智能分類」：選擇消費項目自動帶出財商屬性。
- 薪資入帳時自動彈出「黃金分流建議」，落實「先支付給未來的自己」。

## 🛠️ 專案技術與結構

- **架構**：純前端原生模組化架構（ES6 Modules + CSS Tokens + Glassmorphism 現代科技深色美學）。
- **隱私安全**：Local-First 本機離線優先儲存，支援 JSON 匯出備份與還原。
- **檔案組織**：
