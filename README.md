## 🌟 核心特色與財商理念

### 1. 50 / 30 / 20 黃金資產配置模型 (Elizabeth Warren 經典法則)
- **50% 必要需求 (Needs)**：維持生存與工作的固定支出（房租、三餐、水電瓦斯、交通通勤、基本醫療與保險）。
- **30% 彈性慾望 (Wants)**：提升生活品質與適度犒賞（外食大餐、服飾精品、娛樂展覽、旅遊休閒）。
- **20% 投資與安全儲備 (Invest & Savings)**：讓未來的自己更有錢（指數化 ETF 投資、緊急預備金累積、自我成長進修）。

### 2. 信用卡「零錯亂」財商理解方式
- **【刷卡當下即支出】**：刷卡的瞬間立即記錄消費項目與財商標籤，及時扣減當月預算，杜絕「假性富裕」心理。
- **【繳卡費是內部轉帳，非重複支出】**：繳納信用卡帳單時，屬於「銀行活存 ➔ 信用卡帳戶」的沖銷轉帳，系統絕不重複扣減支出。
- **【真實可用現金 (Real Available Balance)】**：自動計算 `活存存款 - (玉山待繳 + 富邦待繳)`，讓您一眼看清真正能自由支配的資金。

### 3. 雙信用卡 30% 信用額度使用率嚴格風控 (玉山 & 富邦)
- 銀行與聯徵中心評估個人信用時，會高度關注**「信用卡額度使用率（當月刷卡 ÷ 總額度）」**。維持在 30% 以下能打造最頂級的個人信用評分！
- **預設配置**：
  - 💳 **玉山銀行信用卡**：總額度 $60,000 ➔ **每月安全刷卡上限：$18,000 (30%)**
  - 💳 **富邦銀行信用卡**：總額度 $60,000 ➔ **每月安全刷卡上限：$18,000 (30%)**
- 系統內建即時進度刻度與超標預警，刷卡超過 $18,000 時立即發出風控提示。

### 4. 🛡️ 緊急預備金防護盾
- 動態計算當前預備金可支撐幾個月的生活固定開銷（以 3~6 個月為黃金安全基準線）。

### 5. 📊 獨立財務報表分析中心 (月報表 / 季報表 / 年報表)
- **獨立專屬欄目**：完全不佔用主頁面版面，保持首頁清爽俐落。
- **📅 月報表**：任意切換月份，檢視單月收支、50/30/20 分佈與雙卡刷卡總額。
- **📊 季報表**：以每 3 個月為單位回顧季度儲蓄率與開銷水準。
- **🏆 年報表**：年度總回顧，掌握年度資產累積與長期投資進度。
- **🏆 支出分類排行榜 Top 5**：清晰洞察期間花費最高的前 5 大消費類別。

### 6. 🔄 直覺雙帳戶內部轉帳 (左口袋移到右口袋)
- 專屬「📤 轉出帳戶 ➔ 📥 轉入帳戶」介面，徹底解決帳戶調配困惑。
- 內建 **一鍵套用快捷情境**（存入緊急預備金 / 存入證券投資戶 / 繳納玉山卡費 / 繳納富邦卡費）。
- 不計入生活開銷，確保 50/30/20 比例精確無誤。

### 7. 📱 手機桌面版網頁 APP (PWA & iOS Safari 加入主畫面)
- **現代科技奢華風專屬 PNG App Icon**：立體多面水晶鑽石與金色財富上升階梯圖示。
- **iOS / Android 原生沉浸體驗**：透過 Safari「加入主畫面」後，可享有如同原生下載 App 的全螢幕體驗（無瀏覽器網址列干擾）。
- **零延遲極速記帳**：頂部導航列「➕ 記一筆」隨開即記，金額具備獨立呼吸間距與千分位即時大字確認條。
- **薪資入帳智能分流**：收入入帳時自動試算 50/30/20 分流金額，落實「先支付給未來的自己」。

## 🛠️ 專案技術與結構

- **架構**：純前端原生模組化架構（ES6 Modules + CSS Tokens + Glassmorphism 現代科技深色美學）。
- **離線優先 & 零相依**：支援 LocalStorage 本地儲存與 JSON 備份匯出入，雙擊 `index.html` 即可 100% 離線秒開。
- **檔案組織**：
  ```
  Financial-literacy/
  ├── index.html              # 主頁面結構與自包含相容腳本
  ├── manifest.json           # PWA Web App 桌面清單配置
  ├── icons/                  # 現代風專屬 App Icon PNG 圖示庫 (512/192/180)
  ├── css/
  │   ├── main.css            # 核心設計系統、Tokens 與自適應排版
  │   └── components.css      # 信用卡卡片、財務報表、iOS 底部抽屜、輸入框元件
  ├── js/
  │   ├── app.js              # 應用程式入口與狀態管理
  │   ├── financeLogic.js     # 財商配置、月季年報表演算法、雙卡 30% 風控
  │   ├── storage.js          # 本機持久化與備份匯出入
  │   ├── categories.js       # 預設雙軌收支分類庫與財商標籤
  │   └── uiRenderer.js       # 介面動態渲染與報表圖表視覺
  └── README.md               # 專案手冊與財商理念
  ```

## 📱 iPhone (iOS 26) 設定桌面 App 指南

1. 用 iPhone Safari 開啟網址。
2. 點擊瀏覽器底部的 **「分享」** 按鈕（方塊帶向上箭頭）。
3. 點選 **「加入主畫面」**，確認名稱為 **「智富記帳」**。
4. 點擊 **「新增」**，桌面即刻出現專屬水晶鑽石 App 圖示，點開即可全螢幕秒開記帳！
